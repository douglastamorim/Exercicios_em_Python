# Estudos de Python

Repositório criado para registrar minha evolução nos estudos de Python durante minha formação em Análise e Desenvolvimento de Sistemas (ADS).

## 📚 Sobre

Aqui estão reunidos exercícios e pequenos projetos desenvolvidos utilizando a linguagem Python, com foco no desenvolvimento do raciocínio lógico, na resolução de problemas e na aplicação dos conceitos de programação.

## 🧠 Conteúdos praticados

- Variáveis e tipos de dados
- Entrada e saída de dados
- Operadores matemáticos
- Estruturas condicionais (`if`, `elif`, `else`)
- Estruturas de repetição (`for`, `while`)
- Listas e manipulação de dados
- Funções
- Validação de informações
- Tratamento de erros
- Organização e reutilização de código
- Desenvolvimento de pequenos projetos

## 🛠️ Tecnologias utilizadas

- Python 3
- IDE PyCharm
